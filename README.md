Etch-a-Sketch

Este é um projeto desenvolvido como parte do currículo Foundations do The Odin Project. O objetivo foi criar uma versão digital do clássico brinquedo de desenho, permitindo que o usuário interaja com um grid dinâmico.
🔗 Link do Projeto

Veja o projeto funcionando aqui: https://alexandredias-dev.github.io/etch-a-sketch
🚀 Funcionalidades

    Grid Dinâmico: O usuário pode definir o tamanho do grid (ex: 16x16, 64x64).

    Desenho Interativo: O desenho ocorre ao passar o mouse sobre os blocos (efeito hover).

    Reset: Botão para limpar a área de desenho e iniciar um novo grid.

🛠️ Tecnologias Utilizadas

    HTML5: Estrutura básica do projeto.

    CSS3: Estilização, utilizando CSS Grid para a criação do layout.

    JavaScript: Manipulação dinâmica do DOM, loops e gerenciamento de eventos.

🧠 Aprendizados

Este projeto foi fundamental para consolidar conceitos importantes:

    Manipulação do DOM: Criação, remoção e inserção de elementos via JavaScript.

    Eventos: Uso de mouseover para detectar a interação do mouse com cada célula do grid.

    Lógica de Loops: Utilização de estruturas de repetição para gerar o grid com base na escolha do usuário.

    CSS Grid: Entendimento de como criar layouts flexíveis que se adaptam dinamicamente.
